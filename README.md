# Ensino Coletivo de Cordas UFC — React + Tailwind CSS

## Executar localmente
1. Extraia o ZIP e abra a pasta no terminal.
2. Instale as dependências: `npm install`
3. Inicie: `npm run dev`
4. Abra o endereço local informado pelo Vite.

## Estrutura
`src/components/` contém Navbar, Hero, About, News, Game, Participation e Footer. `App.jsx` reúne as seções.

## Observações
Este é um esqueleto responsivo com Tailwind CSS 3 e Vite. Os blocos de imagem são placeholders. Substitua-os por fotos autorizadas e atualize os textos com informações oficiais. O jogo ainda não possui lógica; painel administrativo, login e banco de dados também não estão incluídos.
